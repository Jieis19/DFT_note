# DFT Test Notes

## 1. Overview of DFT (Design For Testability)
- Purpose: Enhance chip testability to facilitate manufacturing inspection and defect detection.
- Key Techniques:
  - Scan Chains
  - Built-In Self-Test (BIST)
  - Boundary Scan (JTAG)
  - Test Point Insertion

## 2. Usage of ATE (Automatic Test Equipment)
- Function: Automatically execute test vectors and collect/analyze test results.
- Workflow:
  1. Load test program
  2. Apply test vectors
  3. Collect output signals
  4. Defect analysis and reporting
- Considerations:
  - Optimize test time
  - Ensure coverage
  - Synchronize hardware/software updates
